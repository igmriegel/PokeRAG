## Field and estimation conventions

| Harness field | Jira / Azure DevOps / Linear field |
| :--- | :--- |
| `TASK-###` | Issue key / external ID |
| Epic / Category | Parent + labels / area path |
| Criticality | Business/security impact |
| Priority | P0 immediate, P1 next, P2 planned, P3 optimize |
| Story Points | Fibonacci complexity, including uncertainty |
| Effort | Expected elapsed engineering effort, excluding review queues |
| Depends on | Blocking issue links |
| Owner | Suggested accountable discipline, not an individual |
| DoD | Acceptance criteria; mandatory test is in the task specification |

No item may move to `Done` from documentation alone unless the finding is exclusively a
documentation defect. Evidence must be generated by the active CI or retained evaluation run.
