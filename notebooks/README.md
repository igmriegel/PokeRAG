# Notebooks Directory (`notebooks/`)

This directory contains Jupyter notebooks used for experimental analysis and metric comparisons:
- `01_data_exploration.ipynb`: Exploratory data analysis of scraped Pokegym rulings and extracted PDFs.
- `02_retrieval_experiments.ipynb`: Comparative evaluation of Dense vs. BM25 vs. Hybrid vs. Re-ranking.
- `03_evaluation_analysis.ipynb`: LLM evaluation metrics visualization (Faithfulness, Correctness, Citation Quality).
